# zaftool.com — static site (Astro)

Statically rendered marketing site for ZAF Tools. Every page ships full HTML, meta, canonical,
Open Graph and JSON-LD (Organization, SoftwareApplication, Breadcrumb, FAQ, HowTo, Article).

## Local
    npm install
    npm run dev        # http://localhost:4321
    npm run build      # -> dist/

## Deploy on Cloudflare Pages (replaces the current React SPA)
Cloudflare Pages > your project > Settings > Builds & deployments:
- Framework preset: Astro
- Build command: `npm run build`
- Build output directory: `dist`
- Node version: 22 (environment variable `NODE_VERSION=22`)

Push this folder to the `main` branch of `Avira1306/Zaf-tool` (replace the old Vite source) and
Cloudflare redeploys automatically. `public/_redirects` handles apex→www and legacy URLs;
`public/_headers` sets caching and security headers.

Custom domains on the Pages project must include BOTH `www.zaftool.com` and `zaftool.com`
for the apex→www 301 to work.

## Content
- Site copy, features, comparisons, personas, pricing, FAQ: `src/data/site.ts`
- Blog posts: `src/content/blog/*.md` (frontmatter: title, description, date, category, image)
- Free templates: generated by `build_templates.py` into `public/templates/`
- Screenshots: `public/img/*.webp`

## Adding a blog post
Create `src/content/blog/my-post.md` with frontmatter and markdown. It appears in /blog and the sitemap on next build.
